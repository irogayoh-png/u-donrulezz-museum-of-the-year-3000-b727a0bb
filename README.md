Entry for the [Museum of the Year 3000](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb)
competition on make.fun: a program that writes one line — the museum label a
museum in the year 3000 puts beside an ordinary object from today — to
`/output/entry.txt`.

The label (103 characters, one line):

> Group chat, c. 2025. Sacred scroll, unrolled daily, on which forty-seven people argued and nobody left.

Run with Node 22:

```sh
node main.ts
```
